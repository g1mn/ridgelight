# Lunar Window

Lunar Window is a static web app for the NASA Space Apps Challenge 2026 challenge "Lunar Landing Site Navigator". Pick a lunar south pole site and see when the Sun and Earth rise and set there, with the terrain model checked against NASA data.

Work on this repository started on 2026-11-14 at 10:00 KST (09:00 Taipei time), when the hackathon began. Unofficial entry, not affiliated with or endorsed by NASA.

License: Apache-2.0 (see LICENSE).

## Run it

Open `web/index.html` (or the root `index.html`) in a browser. No server, no install, no network calls at run time. `node --test` runs the tests. `node tools/build-data.mjs` regenerates `web/gen/*.js` from `data/`, `verify/` and `web/i18n/`.

Screens: south pole map, sky dome (Sun and Earth tracks with the terrain horizon), timeline bar, 3-site comparison with date shift, verification panel. The interface is available in 10 languages (en, ko, ja, zh-Hans, zh-Hant, es, fr, de, pt, vi).

## NASA data used

- NASA JPL Horizons ephemerides and NAIF SPICE kernels: Sun and Earth directions seen from each site (`verify/l1a-summary.json`).
- LRO LOLA digital elevation models: terrain horizon at each site.
- LRO LOLA average visibility maps: reference for the terrain model check (`verify/l1b-summary.json`).
- LROC wide angle camera images: shadow check against real photographs (`verify/m1-summary.json`).

File names and SHA-256 sums of the inputs are in `verify/data-sha256.txt` and in `LW_DATA.sources` inside `web/gen/data.js`. Numbers shown in the app come from the files in `data/` and `verify/`, not from the page code.

## Limits

The terrain model uses public elevation maps at the stated resolution and ignores small boulders and any change in the surface. A match with LOLA maps and LROC images is a consistency check, not a guarantee for a real landing. The check against Horizons tests the implementation, not the physics.
